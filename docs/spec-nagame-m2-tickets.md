# Nagame M2 — ตั๋วเครื่องบิน + การเดินทางในญี่ปุ่น

> สถานะ: SPEC (ยังไม่เริ่มทำ) · วันที่ 2026-10-10 · ต่อจาก `docs/spec-nagame-v1-lite.md`
> หลักเดิมยังใช้: ไม่เสียเงิน, LLM ไม่แต่งตัวเลข, ราคาทุกตัวต้องมีที่มาและเวลา, ไม่จอง ไม่จ่ายเงินแทนผู้ใช้

## 0. สถานะ (อัปเดต 2026-10-10 รอบ 2)

ทำแล้ว:
- **T1** ทุกช่วงเดินทางในแผนรายวันมีปุ่ม "ดูทาง" ไป Google Maps แบบรถไฟ (โตเกียวแยกนาริตะ/ฮาเนดะ) ตรวจแล้วเปิดเห็นขบวนและค่าโดยสารจริง
- **การ์ด "เดินทางในญี่ปุ่น"** แบบแผนที่รถไฟใต้ดิน: สนามบิน → เมือง → สนามบิน + คำตัดสิน JR Pass หนึ่งบรรทัด (คิดจากเพดานค่าโดยสาร ไม่แต่งราคา)
- **เตือนภัยธรรมชาติ** จาก 気象庁 (JSON ระบบใหม่ `/bosai/warning/data/r8/`) แสดงเฉพาะระดับ 警報 ขึ้นไป เฉพาะช่วง 7 วันก่อนเดินทางถึงวันสุดท้าย ลิงก์ตรงไปหน้า 気象庁
- **boarding pass** มีเครื่องบินบินตามเส้นประ + รอยฉีกแบบตั๋วจริง

ตัดสินใจ:
- **ข้อมูลน้อยไว้ก่อน:** ไม่แสดงราคารถไฟรายช่วง (T2/T3 เลื่อน) ไม่แสดงชั่วโมงเดินทางในการ์ด เพราะสูตรระยะทางเส้นตรงพลาดมาก (คาวากุจิโกะ→นิกโก้ ขึ้น ~1 ชม. แต่จริง 3–4 ชม.)
- **Jev ultrafast หาราคาตั๋วไม่ได้:** ทดสอบ 2026-10-10 ด้วย Chrome อัตโนมัติ (profile มี cookie แล้ว) Google Flights ขึ้น "อ๊ะ มีบางอย่างผิดพลาด" และ Skyscanner ขึ้น CAPTCHA "กดค้าง" ห้ามข้าม CAPTCHA และรันบน Vercel ไม่ได้ → แหล่งราคาตั๋วรอเจ้าของเลือก

ค้าง: แหล่งราคาตั๋ว (F1–F3), ตารางค่ารถไฟ (T2), งบรวม (T3), แก้สูตรชั่วโมงเดินทางในแผนรายวัน

## 1. ปัญหาตอนนี้

- หน้าตั๋วเปิด Google Flights ตามวันได้ แต่**ไม่บอกราคาเลย** ผู้ใช้ต้องกดออกไปดูเอง
- การเดินทางในญี่ปุ่นมีแค่ป้าย "🚆 รถไฟ ~2 ชม." **ไม่มีค่าเดินทาง ไม่มีลิงก์ดูขบวนจริง ไม่บอกว่า JR Pass คุ้มไหม**
- งบรวมของทริปคำนวณไม่ได้ เพราะขาดสองอย่างนี้

## 2. ตัวเลือกแหล่งราคาตั๋วเครื่องบิน (ตรวจ 2026-10-10)

| ทางเลือก | สถานะ | ข้อดี | ข้อเสีย | ตัดสิน |
|---|---|---|---|---|
| Google Flights deep link (ที่ใช้อยู่) | ใช้ได้ | ราคาสด ครบทุกสาย | เราไม่เห็นราคา | **เก็บไว้** เป็นปุ่ม "เทียบราคาสด" |
| Travelpayouts / Aviasales Data API | ฟรี ต้องสมัครรับ token | มีราคา ใส่ในหน้าได้ + มีค่าคอมจาก affiliate | เป็นราคา cache ที่ผู้ใช้ Aviasales เคยค้นใน 48 ชม. เก็บไว้ไม่เกิน 7 วัน ไม่ใช่ราคาสด | **เลือก** เป็น "ราคาอ้างอิง" |
| Amadeus Self-Service | **ปิดแล้ว 17 ก.ค. 2026** | – | key ใช้ไม่ได้ เหลือแต่ Enterprise | ตัดทิ้ง |
| Browser agent ค้น Google Flights (worker ของเจ้าของ) | พัก | ราคาสดจริง | Google บล็อก profile อัตโนมัติ, ดูแลยาก | พักต่อ ไม่อยู่ใน M2 |
| Kiwi Tequila / Skyscanner API | ไม่เปิดรับรายย่อย | – | – | ตัดทิ้ง |

**ข้อสรุป:** แสดง "ราคาที่เจอล่าสุด" จาก Travelpayouts พร้อมบอกเวลา แล้วมีปุ่มไปเช็กราคาสดใน Google Flights ทุกครั้ง

## 3. ฟีเจอร์ตั๋วเครื่องบิน (F)

### F1 ราคาอ้างอิงบน boarding pass
- server route ใหม่ `GET /api/tabi/fares?from=BKK&to=TYO&depart=YYYY-MM-DD&return=YYYY-MM-DD`
  - เรียก Travelpayouts `/aviasales/v3/prices_for_dates` แบบ `currency=thb`, `market=th`
  - cache ฝั่ง server 6 ชม. และใช้ rate limit เดิมของ `/api/tabi`
  - token อยู่ใน env `TRAVELPAYOUTS_TOKEN` (เจ้าของใส่เอง ห้ามส่งในแชท)
- ข้อความบนบัตร: `เจอล่าสุด ~฿12,400 ไป-กลับ · อัปเดต 3 ชม.ก่อน`
- ไม่มีข้อมูลเส้นนั้น: `ยังไม่มีราคาอ้างอิงเส้นนี้ กดเช็กราคาสดได้เลย`
- ไม่มี token หรือ API ล่ม: ซ่อนราคาเงียบ ๆ หน้าเดิมทำงานต่อ (fail-open แบบไม่โกหก)
- ปุ่มสองปุ่ม: `เช็กราคาสดใน Google Flights` และ `ดูตั๋วนี้ใน Aviasales` (affiliate)

### F2 ปฏิทินวันถูกสุดของเดือน
- ถ้ายังไม่ตั้งวัน ใช้ `departure_at=YYYY-MM` หาวันที่ถูกสุดที่เจอในเดือนนั้น
- แสดงแถบ 5 วันที่ถูกสุด กดแล้วตั้งเป็นวันออกเดินทางของทริปเลย
- ข้อความ: `วันที่เจอราคาถูกสุดในเดือน พ.ค.` ไม่ใช้คำว่า "ถูกที่สุด" แบบรับประกัน

### F3 งบตั๋วในภาพรวมทริป
- เก็บราคาอ้างอิงลง `SavedTrip.budget.flight = { thb, foundAt, source }`
- นับรวมในงบทริป (ดู T3)

### กติกาความซื่อสัตย์ของราคา (ห้ามหลุด)
1. ทุกราคามีคำว่า "~" และเวลาที่เจอ
2. ห้ามเขียนว่า "ราคาตอนนี้" หรือ "ถูกที่สุด" แบบเด็ดขาด
3. แสดงหมายเหตุ affiliate หนึ่งบรรทัด: `ทาบิอาจได้ค่าแนะนำเมื่อจองผ่านลิงก์ โดยราคาไม่เพิ่มขึ้น`
4. LLM (Jev) ไม่แตะตัวเลขราคา ตัวเลขมาจาก code เท่านั้น

## 4. การเดินทางในญี่ปุ่น (T)

ไม่ใช้ API แบบเสียเงิน (Navitime / Jorudan / Google Directions API เสียเงินทั้งหมด)

### T1 ลิงก์ดูขบวนจริงทุกช่วงเดินทาง (ทำง่ายสุด คุ้มสุด)
- ทุก item `kind: "move"` ในแผนรายวันมีปุ่ม `ดูขบวนรถใน Google Maps`
- ใช้ Maps URL ที่ Google เปิดให้ใช้ฟรี:
  `https://www.google.com/maps/dir/?api=1&origin=Tokyo+Station&destination=Kyoto+Station&travelmode=transit`
- ต้นทาง/ปลายทางใช้สถานีหลักของเมือง (เพิ่ม `station` ใน `lib/tabi/cities.ts`)
- ต้องทดสอบบนมือถือจริงว่าเปิดแอป Google Maps และแสดงชินคันเซ็นถูก

### T2 ค่าเดินทางโดยประมาณ
- ไฟล์ข้อมูล `data/transport/fares.json`: ~40 คู่เมืองหลัก (โตเกียว–เกียวโต, โอซาก้า–ฮิโรชิม่า, โตเกียว–คานาซาว่า, …)
  - field: `from, to, mode, minutes, fareYen, supplementYen, source, checkedAt`
  - ตัวอย่างจริง: โตเกียว–เกียวโต Nozomi ~¥14,000 ที่นั่งจอง, ~2 ชม. 15 นาที
- คู่ที่ไม่อยู่ในตาราง: ไม่เดาราคา แสดงแค่เวลาประมาณ + ลิงก์ T1
- Jev ช่วยหาและสรุปจากหน้าเว็บทางการ แล้วให้ Claude ตรวจทานแบบเดียวกับข้อมูลช่วงปิดฤดูกาล

### T3 งบทริปรวม
- การ์ดใหม่ในหน้าแผนรายวัน: `งบเดินทางโดยประมาณ`
  - ตั๋วเครื่องบิน (F1) + รถไฟในญี่ปุ่น (T2) + ค่าเดินทางสนามบินเข้าเมือง
  - แสดงเป็นเยนและบาท (อัตราแลกเปลี่ยนจากแหล่งฟรี เช่น ECB/frankfurter พร้อมวันที่)
- ไม่รวมที่พัก/อาหารใน M2 (ไม่มีข้อมูลจริง)

### T4 JR Pass คุ้มไหม
- เอาค่ารถไฟทั้งทริป (T2) มาเทียบกับราคา pass แล้วบอกตัวเลขตรง ๆ
  - `รถไฟทั้งทริป ~¥32,000 · JR Pass 7 วัน ¥53,000 → ซื้อตั๋วรายเที่ยวถูกกว่า ~¥21,000`
- ราคา pass เก็บใน `data/transport/passes.json` พร้อม source และ checkedAt
  - JR Pass 7 วัน ordinary: ¥50,000 → ¥53,000 ตั้งแต่ 1 ต.ค. 2026 (แหล่งข้อมูลยังขัดกันเรื่องช่องทางขาย ต้องเช็ก japanrailpass.net ก่อนใส่)
  - Nozomi/Mizuho ไม่รวมใน JR Pass ต้องจ่ายเพิ่ม (โตเกียว–เกียวโต ¥4,960)
  - pass ภูมิภาคที่ตรงกับเส้นทางของทาบิ: Kansai Wide, Hokuriku Arch, JR East, Kyushu
- ทาบิพูดคำตัดสินจาก phrase template; Jev ไม่คำนวณ

### T5 จากสนามบินเข้าเมือง
- การ์ดคงที่ต่อสนามบิน gateway 6 แห่ง เช่น NRT → Narita Express / Keisei Skyliner พร้อมเวลาและค่าประมาณ
- แนะนำบัตร IC (Suica/PASMO/ICOCA) หนึ่งบรรทัด

## 5. ไอเดียจาก japantripplanners.com/interactive-map

สิ่งที่เขามี: แผนที่ญี่ปุ่นแบบเปิดชั้นข้อมูล (วัด 168, ปราสาท 70, ธรรมชาติ 168, สวน 480, มรดกโลก 51 …),
บันทึกสถานที่, ฐานข้อมูลแบบเสียเงิน (ร้านอาหาร, ออนเซ็น, จุดชมซากุระ, สถานีและเส้นทาง), คู่มือรายภูมิภาค, ลิงก์ affiliate, newsletter
**ไม่มี** AI, เวลาเดินทาง, ค่าเดินทาง และไม่บอกว่าจัด itinerary อย่างไร

| ชั้นข้อมูลตามหมวด (วัด/ธรรมชาติ/ออนเซ็น) บนแผนที่ | **เอา** (M3) | เรามี 1,452 จุดพร้อม tag อยู่แล้ว ทำเป็นโหมด "สำรวจแผนที่" ได้ถูก |
| ชั้นตามฤดู (ซากุระ/ใบไม้แดง/หิมะ ตามเดือนที่เลือก) | **เอา** (M3) จุดขายของเรา | เรามีคะแนนฤดูต่อจุด + ข้อมูลช่วงปิด เขาไม่มี |

| ฐานข้อมูลแบบเสียเงิน / premium | ไม่เอา | ทิศทางเราคือฟรี + affiliate |

**ความเห็น:** แผนที่ของเขาเป็น "สมุดภาพให้คนหาเอง" ส่วนของเราเป็น "แมวที่จัดทริปให้"
เอาแผนที่สำรวจมาเป็นส่วนเสริมได้ แต่ต้องไม่แทนแชท จุดต่างที่แข็งที่สุดคือ ฤดูกาล + ช่วงปิด + ค่าเดินทาง + ภาษาไทย

## 7. Acceptance criteria

1. ทริปที่มีวันเดินทาง: boarding pass แสดงราคาอ้างอิง พร้อม "~" และเวลาที่เจอ หรือข้อความ "ยังไม่มีราคาอ้างอิง" ไม่มีกรณีที่แสดงตัวเลขโดยไม่มีเวลา
2. ปิด token หรือ API ล่ม: หน้าตั๋วยังทำงานเหมือน M1 ทุกอย่าง ไม่มี error ขึ้นหน้า
3. ทุกช่วง `move` ในแผนรายวันมีลิงก์ Google Maps แบบ transit ที่เปิดแล้วเห็นเส้นทางรถไฟจริง (ทดสอบ 5 คู่บนมือถือ)
4. คู่เมืองที่ไม่มีในตาราง T2 ไม่แสดงราคา
5. การ์ด JR Pass แสดงตัวเลขเทียบทั้งสองฝั่ง และอ้างวันที่ตรวจราคา pass
6. Eval เดิม 18/18 ยังผ่าน และเพิ่ม eval ราคา: ตัวเลขทุกตัวใน reply ต้องตรงกับข้อมูลจาก code
7. หมายเหตุ affiliate แสดงทุกครั้งที่มีลิงก์ affiliate
