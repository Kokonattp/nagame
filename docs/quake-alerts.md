- **Invalidation:** ผู้ใช้เปลี่ยนวัน/เส้นทาง → ปุ่มส่ง upsert ใหม่อัตโนมัติ; ปิดแจ้งเตือน → DELETE;
  push service ตอบ 404/410 → worker ลบแถว; ทริปจบเกิน 7 วัน → worker ลบ
- **ความจำว่าส่งแล้ว** อยู่ในหน่วยความจำ worker (1 ชม.) — รีสตาร์ทแล้วอาจส่งซ้ำได้ 1 ครั้ง (ยอมรับ)
- **ไม่รองรับ:** เบราว์เซอร์ที่ไม่มี Push API, iPhone ที่ไม่ได้เพิ่มลงหน้าจอโฮม (แสดงวิธีแทน), ทริปที่ยังไม่ใส่วันออกเดินทาง
- **ข้อมูลส่วนตัว:** เก็บแค่ endpoint+keys, tripId, รายชื่อจังหวัด (อังกฤษ), วันเริ่ม/จบ — ไม่มีชื่อ/บัญชี/ตำแหน่ง GPS
- **endpoint** รับเฉพาะ https บนโฮสต์ push ที่รู้จัก (FCM, Mozilla, Apple, Windows) — กัน worker ยิงไปที่อื่น
