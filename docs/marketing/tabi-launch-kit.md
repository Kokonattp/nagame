# ชุดเปิดตัวทาบิ: โพสต์กลุ่มเที่ยวญี่ปุ่น + คลิปสั้น

> สำหรับ: เจ้าของ (โพสต์เอง) · ใช้กับกลุ่ม Facebook แนวเที่ยวญี่ปุ่นด้วยตัวเอง, TikTok, Reels
> อ่านกฎของแต่ละกลุ่มก่อนโพสต์ หลายกลุ่มห้ามโฆษณา ให้เล่าแบบ "ทำเครื่องมือมาแจก ขอคำติ"

## หลักที่ใช้ทุกโพสต์
- เปิดด้วยปัญหาที่คนในกลุ่มเจอจริง ไม่ใช่ชื่อแอป
- โชว์ผลลัพธ์เป็นรูป (รูปสรุปทริปจากปุ่ม "แชร์ทริปให้เพื่อน")
- บอกตรง ๆ ว่าฟรี ไม่ต้องสมัคร และยังไม่ได้ขายตั๋วเอง
- ขอคำติ คนจะตอบมากกว่าขอให้ลอง
- ลิงก์ไว้ในคอมเมนต์แรก ถ้ากลุ่มไม่ชอบลิงก์ในโพสต์

## โพสต์ 1 — ปัญหาวางเส้นทาง (ใช้ได้ทุกช่วง)
```
ใครเคยวางทริปญี่ปุ่นเองแล้วงงบ้างคะ ว่าจะนอนกี่คืนเมืองไหน นั่งรถไฟกี่ชั่วโมง 🥲

เลยทำผู้ช่วยตัวเล็ก ๆ ชื่อ "ทาบิ" เป็นแมว 🐱
พิมพ์แค่ "ไป พ.ย. 5 วัน อยากดูใบไม้แดง"
ทาบิจะเสนอเส้นทาง 3 แบบ จัดแผนรายวันพร้อมเวลาเดินทาง
บอกด้วยว่าคุ้มซื้อ JR Pass ไหม และที่ไหนปิดตามฤดู

ฟรี ไม่ต้องสมัคร ทริปเก็บในเครื่องตัวเอง
ยังไม่สมบูรณ์ อยากได้คำติจากคนที่ไปมาแล้วค่ะ 🙏
(ลิงก์อยู่ในคอมเมนต์)
```
แนบ: รูปสรุปทริป 1 รูป

## โพสต์ 2 — ก่อนฤดูดัง (ลงก่อนซากุระ ~ต้น มี.ค. / ใบไม้แดง ~ต้น ต.ค.)
```
เดือน[เมษา] ไปญี่ปุ่นเที่ยวไหนดี 🌸
สรุปไว้ให้แล้วทีละเดือน: อากาศ คนเยอะไหม ที่ไหนยังปิด + เส้นทางตัวอย่าง 5 วัน
👉 nagame.vercel.app/japan/[april]

กดปุ่มเดียว ทาบิจัดเป็นแผนรายวันให้ต่อเลย
ถ้าเจอข้อมูลผิด บอกได้นะคะ จะรีบแก้
```

## โพสต์ 3 — ชวนแชร์ทริป (หลังมีคนใช้แล้ว)
```
ไปญี่ปุ่นกับเพื่อนแล้วต้องส่งแผนให้ทุกคนดูใช่ไหมคะ
ตอนนี้กด "แชร์ทริปให้เพื่อน" ได้รูปสรุปน่ารัก ๆ + ลิงก์
เพื่อนเปิดแล้วเห็นแผนเดียวกัน ปรับต่อเองได้ ทริปเราไม่เปลี่ยน
ใครวางทริปเป็นแก๊งลองดูค่ะ 🐱✈️
```

## คลิปสั้น 30 วินาที (TikTok / Reels / Shorts)
| วินาที | ภาพ | ข้อความบนจอ / เสียง |
|---|---|---|
| 0–3 | หน้าจอมือถือ ทาบิขยับตัว | "วางทริปญี่ปุ่น 5 วัน ใน 30 วิ" |
| 3–8 | พิมพ์ "ไป พ.ย. 5 วัน อยากดูใบไม้แดง" | (เสียงคีย์บอร์ด) |
| 8–13 | การ์ดเส้นทาง 3 แบบเด้งขึ้น | "ได้ 3 เส้นทาง เลือกได้เลย" |
| 13–19 | กดเส้นทาง → แผนที่ → ใส่ในทริป | "ชอบที่ไหน กดใส่ทริป" |
| 19–25 | แผนรายวัน ทาบิวิ่งบนวัน + เวลาเดินทาง | "จัดรายวันให้ พร้อมเวลานั่งรถ" |
| 25–30 | กดแชร์ → รูปสรุปทริป | "ส่งให้แก๊งในไลน์ ฟรี ไม่ต้องสมัคร · nagame.vercel.app" |

ถ่ายจากมือถือจริงด้วยการอัดหน้าจอ ไม่ต้องตัดต่อเยอะ ใส่เพลงเบา ๆ
